AR Sudoku Solver is an Android application that detects Sudoku grids using the phone camera, recognizes their numbers, solves the puzzle, and displays the solution directly on the detected grid.

The application uses OpenCV for image processing, perspective transformations, and grid detection, together with a neural network for digit recognition.
