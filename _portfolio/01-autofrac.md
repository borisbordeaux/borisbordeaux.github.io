AutoFrac is a C++ software for the computer-aided design of lacunar fractal structures.

The software implements the Boundary-Controlled Iterated Function System (BC-IFS) model and provides tools for visualizing and automatically constructing fractal structures. Fractal topologies can be described using Lua scripts, which are then interpreted and rendered by the software.

The project was developed after my PhD.
